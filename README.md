# This library contains the following:

## [Models](https://github.com/greentextterminal/DigitalDesignLibrary/tree/main/Models)
This folder contains behavioral models

## [Modules](https://github.com/greentextterminal/DigitalDesignLibrary/tree/main/Modules)
This folder contains various synthesizable RTL modules

## [Miscellaneous](https://github.com/greentextterminal/DigitalDesignLibrary/tree/main/Miscellaneous)
This folder contains various techniques/tips/best practices/prebuilt testbench tasks & functions/etc...

## [Testbenches](https://github.com/greentextterminal/DigitalDesignLibrary/tree/main/Testbenches)
This folder contains testbenches to test the synthesizable RTL modules found in [Modules](https://github.com/greentextterminal/DigitalDesignLibrary/tree/main/Modules)
